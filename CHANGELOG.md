# Changelog

## 1.0.0 (2026-11-05)

The first release.

- Tokens: paper and ink, eight tones with five shades each (pop, fill, soft, ink, mark), a brand tone, type scale, spacing, wobble radius, pencil shadows, tilt and motion. Light and dark themes, with 140 contrast pairs checked by `npm run check`.
- Base: `class="hui"` turns on the graph paper, the Caveat and Shantell Sans fonts and friendly defaults for plain HTML.
- Components: button, chip, link, badge, kbd, code, highlight, marker, scribble, strike, circle, dividers, doodles, card, frame, tape, sticky note, callout, banner, window, annotation, field, input, textarea, select, checkbox, radio, switch, range, nav bar, logo, tabs, dropdown menu, breadcrumb, pagination, footer, alert, toast, tooltip, dialog, progress, spinner, skeleton, accordion, table, avatar, stat, steps, checklist, quote, pricing card, option card, empty state.
- Script: reveal on scroll, tabs with arrow keys, dialogs, menus that close on outside click and Escape, toasts, copy buttons and a light, dark or auto theme switch.
- Docs: showcase page, foundations and one doc per component family, a landing page and an app screen as examples, screenshots.
- Optional React wrappers in `react/`.
- `SKILL.md`, so Claude Code can build pages with HappyUI.
