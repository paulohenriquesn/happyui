Start in a minute

Three lines and you are in.

Add the two fonts, the stylesheet and the script. Then put class="hui" on your body and start using the components.

No bundler, no config. If you use npm, it is the same files. The script is optional: everything still renders without it.

<!-- 1. the two fonts -->
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Caveat:wght@400..700
  &family=Shantell+Sans:ital,wght@0,300..800;1,300..800">

<!-- 2. HappyUI -->
<link rel="stylesheet" href="happyui.min.css">
<script src="happyui.js" defer></script>

<!-- 3. use it -->
<body class="hui">
  <button class="hui-button hui-button--primary">
    Hello!
  </button>
</body>
